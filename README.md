# 용인특례시장 후보 비교 웹 (2026)

제9회 전국동시지방선거 용인특례시장 후보 3인의 공약·인적사항을 비교하는 React 웹앱입니다.
데이터는 중앙선거관리위원회 후보자정보공개자료와 후보자 제출 5대 공약(PDF)에서 추출했습니다.

**라이브 URL**: https://notohs.github.io/yongin-mayor-2026-compare/
(GitHub Pages · 저장소 [notohs/yongin-mayor-2026-compare](https://github.com/notohs/yongin-mayor-2026-compare))

## 배포 (GitHub Pages)

```bash
cd web
npm run build
npx gh-pages -d dist        # dist/를 gh-pages 브랜치로 배포
```

소스 변경은 `main` 브랜치에 push, 정적 결과물은 `gh-pages` 브랜치로 배포됩니다. `vite.config.ts`의
`base: './'`(상대경로) 덕분에 하위 경로(`/yongin-mayor-2026-compare/`)에서도 자산이 정상 로드됩니다.

## 실행 방법

```bash
cd web
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 프로덕션 빌드 (dist/)
npm run preview  # 빌드 결과 미리보기
```

> Node 18에서 동작합니다(권장 20+). 빌드는 `tsc` 타입체크 후 Vite 번들링을 수행합니다.

## 화면 구성 (비교 중심)

- **종합 비교**: 후보 요약 카드 3개 + 핵심 정보(나이·직업·학력·비전) 비교표
- **공약 비교**: 두 가지 모드 토글
  - **분야별 정면 비교(기본)**: 분야(교통·반도체·경제·복지·도시·교육·문화·주거)를 고르면, 그 분야의
    **5대 공약 + 선거공보 세부 공약**을 후보 3인 나란히 비교. 관련 공약이 없는 후보는 “관련 공약 없음”
  - **후보별 공약**: 후보별 5대 공약을 3열로(분야 태그 + 목표/이행방법/이행기간/재원조달 펼침)
- **인물·검증**: 선관위 자료 제출 현황(선거공보·선거공약서·5대공약 등록 여부) · 학력·경력·재산·
  납세·체납·병역·전과를 항목별로 나란히 비교. **미등록 자료는 ‘성실 제출’ 참고 지표**로 빨갛게 명시
  (종합 비교 카드·후보 상세 모달에도 표시)
- **공약 퀴즈**: 후보를 가린 블라인드 공약 선택 퀴즈(아래 참고)
- 후보 카드의 **상세 정보 보기** → 전체 정보 모달

## 공약 퀴즈 (블라인드)

- 시작 시 **닉네임**을 입력합니다. 각 문항에는 **← 이전** 버튼이 있어 되돌아가 답을 바꿀 수 있고,
  이전 선택은 그대로 복원됩니다.
- **정책 문항**: 비슷한 주제에서 후보별 접근이 다른 지점을 묶어, 후보 이름·정당을 가린 채
  선택지를 **랜덤 순서**로 보여줍니다.
  - 선택지가 **3개인 문항은 최대 2개**(가중치 1개=1점, 2개=각 0.7점), **2개인 문항은 1개**만 선택.
  - 5문항은 5대 공약 기반(후보 3인, 3지선다), 나머지는 **선거공보 세부 공약 기반**(현근택·이상일 2지선다,
    송창훈은 공보 세부 공약이 없어 미등장).
  - 전체 문항은 **최소 10 ~ 최대 20문항** 범위로, 공약이 많아 문항이 늘어나도 20개를 넘지 않습니다
    (현재 정책 13 + 검증 3 = 16문항). 상한은 [`quizEngine.ts`](src/utils/quizEngine.ts)의
    `MAX_QUIZ_QUESTIONS`.
- **검증 문항(데이터 기반 자동 생성)**: 후보의 **병역·체납·전과** 기록을 후보명 없이 제시하고
  “그래도 괜찮으신가요?”를 **3지선다**로 묻습니다.
  - **괜찮다** → 감점 없음
  - **내키지는 않지만, 후보의 자질이 매우 훌륭하다면 뽑을 수도 있다** → 해당 후보 **−1점**
  - **절대 안된다** → 해당 후보 **추천에서 배제**
  - 생성 조건: 병역(본인/18세 이상 직계비속 미이행 시 — 현재 데이터는 전원 이행 → 0문항),
    체납(이력 보유 후보 — 현근택 1문항), 전과(**개별 항목마다** 1문항 — 송창훈 2문항)
- **점수 = 정책 가중치 합 − 검증 감점**. 배제 후보를 제외하고 최고 점수 후보를 **추천**합니다
  (동점 시 공동 추천, 전원 배제 시 “추천할 후보 없음”).
- 결과는 닉네임·날짜·지역과 함께 브라우저 **localStorage**(`quiz-results-v3`)에 저장되며,
  **이전 결과 보기**에서 (현재 지역 기준) 다시 조회·삭제할 수 있습니다. 외부 전송은 없습니다.
- 정책 문항은 선거별 [`src/data/quizThemes.ts`](src/data/quizThemes.ts), 검증 문항 생성·가중치·집계
  로직은 [`src/utils/quizEngine.ts`](src/utils/quizEngine.ts), 저장은
  [`src/utils/quizStorage.ts`](src/utils/quizStorage.ts) 에 있습니다.

## 다른 지역(선거) 추가하기

데이터는 **선거구 단위 모듈**(`src/data/regions/<id>/`)로 묶여 있고, `regions/index.ts` 가 폴더를
자동 수집합니다. 추가 방법은 두 가지입니다.

### A. 코드로 영구 추가 (CLI)

1. `npm run new:region <id>` — 모듈 + `data-sources/<id>/` 스캐폴딩.
2. `data-sources/<id>/` 에 선거공보·공약집 PDF를 넣고 `npm run ingest <id>` 로 텍스트/OCR 추출.
3. `src/data/regions/<id>/` 모듈을 채우면 빌드 시 자동 노출. (자세히: [DATA_GUIDE.md](DATA_GUIDE.md))

### B. 관리자 콘솔로 즉시 추가 (브라우저, 코드 없이)

헤더의 **🛠 관리자 콘솔** 버튼:

1. **선관위 자료 링크**(정책·공약마당 / 선거통계시스템)로 가서 후보 PDF를 내려받습니다.
2. **선거구명**(예: `경기도지사 선거`)을 입력하고, 그 선거구의 **모든 후보 PDF를 한 번에 업로드** →
   브라우저 안에서 텍스트 추출(이미지 PDF는 **tesseract.js 한국어 OCR**, 외부 전송 없음). 추출
   결과로 **선거구 초안(JSON)** 을 자동 생성(입력한 선거구명 + 후보 기호/이름/정당 추정).
3. JSON을 보완한 뒤 **미리보기 적용** → `localStorage` 에 저장되어 지역 선택기에 추가되고,
   종합비교·공약비교·인물검증·공약퀴즈 4개 화면에서 바로 분석됩니다.
4. **JSON 내보내기** 로 받은 파일을 `src/data/regions/<id>/` 모듈로 옮겨 커밋하면 영구 반영됩니다.

> 콘솔은 보조 입력 도구입니다. 스캔 PDF의 한국어 OCR은 느리고 오탈자가 있어, 생성된 초안은
> **검토·보완이 필요한 데이터**입니다(공약 분류·전과/재산 수치 등). 관련 코드:
> [`AdminConsole`](src/components/admin/AdminConsole.tsx) · [`pdfExtract`](src/utils/pdfExtract.ts) ·
> [`draftElection`](src/utils/draftElection.ts) · [`customElections`](src/utils/customElections.ts)

지역이 둘 이상이면 헤더에 **지역 선택기**가 자동으로 나타나며, 모든 화면이 선택한 지역 기준으로
동작합니다. 각 선거는 `id`로 구분되고 퀴즈 결과도 지역별로 저장됩니다.

## 데이터 구조

- 선거(지역) 묶음: [`src/data/elections.ts`](src/data/elections.ts) — `elections: Election[]`
- 용인 후보 데이터: [`src/data/candidates.ts`](src/data/candidates.ts)
- 타입 정의: [`src/data/types.ts`](src/data/types.ts)
- 포터블 사본: [`public/candidates.json`](public/candidates.json), 프로젝트 루트 `../candidates.json` (`{ elections: [...] }`)

모든 후보는 동일한 `Candidate` 포맷을 따릅니다(기호·정당·슬로건·비전·인적사항·5대 공약·전과·납세·병역·재산).
각 공약에는 분야 `category`(교통·반도체·경제·복지·도시·교육·문화·주거)가 부여되어 있으며,
분야 메타데이터는 [`src/data/categories.ts`](src/data/categories.ts) 에 있습니다.
금액 단위는 **천원**이며, 재산 음수(△)는 채무 초과를 의미합니다.

### 선거공보 세부 공약

5대 공약서 외에 **선거공보(공약집)** 에 담긴 분야별 세부 공약을 별도로 데이터화했습니다
([`src/data/bulletinPolicies.ts`](src/data/bulletinPolicies.ts)). 후보 상세 모달의 “선거공보 세부
공약” 섹션에서 분야별로 펼쳐볼 수 있습니다.

- **현근택**: 이미지 PDF → OCR + 시각 판독. 「용인 도약 10대 공약」 및 분야별 ‘1등 도시’ 공약 (12개 분야)
- **이상일**: 텍스트 공약집 → 경제·청년·소상공인·농업·교통·교육·문화·복지·환경 (9개 분야). 읍·면·동별 공약 목록은 비교 균형상 제외
- **송창훈**: 선거공보가 표지·인적사항 중심으로 별도 분야 공약 없음 → 5대 공약으로 갈음

> 이미지 PDF(현근택)는 OCR 후 사람이 시각 판독해 보정했으나, 일부 소형 글씨는 원문과 미세한 차이가 있을 수 있습니다.
